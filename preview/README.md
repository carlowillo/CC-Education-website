# Download the internal preview

1. Open `education-reach-preview.html` in this GitHub folder.
2. Choose **Download raw file** (the download icon in the file toolbar).
3. Open the saved HTML file from your computer using Chrome, Edge, Safari or Firefox.

If GitHub says the file is too large to display, it can still be downloaded. Alternatively use the repository **Code → Download ZIP**, extract it, and open `preview/education-reach-preview.html`.

The preview is self-contained: no installation or server is needed to view it and use the mode/filter controls. It includes 140 genuine saved travel areas for 70 open initiatives, arriving at 08:30 London time on 30 October 2026. Twenty other open initiatives are excluded until full site postcodes are confirmed. Live recalculation and arbitrary postcode lookup need the server.

This contains internal data. Keep the repository private and share only with authorised colleagues.

## Exploring the map

Numbered circles group nearby initiatives; select one to zoom in or expand shared locations. Town/city labels work offline. Use **Journey settings** for arrival options, **Map key & layers** for labels/street tiles, and **Expand map** for a larger view. Initiative details sit beside the map on desktop and below it on mobile.
