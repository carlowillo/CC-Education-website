# Download the internal preview

1. Open `education-reach-preview.html` in this GitHub folder.
2. Choose **Download raw file** (the download icon in the file toolbar).
3. Open the saved HTML file from your computer using Chrome, Edge, Safari or Firefox.

If GitHub says the file is too large to display, it can still be downloaded. Alternatively use the repository **Code → Download ZIP**, extract it, and open `preview/education-reach-preview.html`.

The preview is self-contained: no installation or server is needed to view it and use the mode/filter controls. It includes 79 source full-postcode locations and 53 labelled representative-postcode estimates, dynamic filter counts, and stage colours. Saved coverage contains 264 genuine TravelTime areas for all 132 initiatives, arriving on Monday 23 November 2026 at 08:30 London time. The default view shows 90 Open initiatives, including 20 estimates. Selecting other stages includes future scenarios; the footer’s Map settings control can exclude estimated locations. Saved initiative/representative postcodes can be searched offline. Other postcode searches send only the entered postcode to Postcodes.io and require internet access. Live journey recalculation requires the server.

This contains internal data. Keep the repository private and share only with authorised colleagues.

## Exploring the map

Numbered circles group nearby initiatives; select one to zoom in or expand shared locations. Town/city labels work offline. The purple number at the bottom shows how many initiatives match the filters. Search and travel modes share one toolbar. Use **Map key & layers** for labels/street tiles and **Expand map** for a larger view. Optional journey settings, the initiative list, data review and coverage details are available from the footer. Initiative details sit beside the map on desktop and below it on mobile.
